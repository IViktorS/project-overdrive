## Что за игра

2D roguelite twin-stick шутер. Тематика — тяжёлая музыка, концерты, инструменты как
оружие. Игрок-музыкант; базовое оружие — гитара, стреляющая звуковой волной «»)))».
Ориентиры: The Binding of Isaac, Enter the Gungeon, Hades.

**Ядро боя:** мало врагов, каждый опасен → всё держится на читаемости атак и
позиционировании (НЕ bullet-heaven, НЕ ритм-игра).

**Дизайн-документ:** `C:\Users\Viktor\Downloads\Дизайн-документ_ музыкальный roguelite-шутер.docx`
(лежит вне репозитория). Есть дополнение про визуал снаряда — «контур-огибающая»
как форма фронта волны (зубчатость фронта = грязность сигнала/Distortion).

## Текущее состояние (этап 1 по плану дока: комната, игрок, манекены)

Готово:
- **Движение** (`PlayerMovement.cs`): WASD через Rigidbody2D, разгон/торможение,
  рывок (dash) с i-frames, машина состояний `Normal`/`Dashing`.
- **Прицел** (`PlayerAim.cs`): считает `AimWorldPoint`, `AimDirection`, `FacingIndex`
  (0..7). Это «мозг» — ничего не рисует.
- **Индикатор прицела** (`AimIndicator.cs`): временная палка-указатель (заглушка).
- **Стрельба** (`GuitarWeapon.cs`): по ЛКМ спавнит префаб волны, кулдаун ~0.25 c
  (темп из дока), буфер ввода ~0.1 c; визуальная отдача спрайта + звук выстрела.
- **Волна** (`Wave.cs` + `WaveStats.cs`): летящий снаряд (MovePosition), хитбокс
  щедрее визуала в 1.5×, затухание по дистанции и по пробитию. `WaveStats.Clone()`
  — чтобы будущие педали меняли КОПИЮ характеристик.
- **Манекен** (`Dummy.cs`): HP + реакция на попадание.
- **Game feel на попадании:** хитстоп 40 мс (`TimeController.cs`, через `Time.timeScale`),
  белая вспышка манекена, звук попадания. Звук — `RandomSound.cs` (4–6 вариаций + питч ±3%).

Следующий шаг: **камера** — follow-риг + лёгкий directional bump на выстрел
(по образцу демки game feel). Потом этап 2 — первый простой враг.

Приоритет полировки game feel (из дока): звук попадания > хитстоп > вспышка врага >
отдача > тряска.

## Ключевые архитектурные решения (не ломать)

1. **Прототип на примитивах.** Графики нет и не нужно до этапа 5; спрайты заменяемы,
   код от арта не зависит.
2. **«Мозг» отдельно от «вида».** Данные (`AimDirection`, `FacingIndex`, состояние)
   — сейчас; спрайты/анимации — позже. Рендер персонажа будет 3/4 «Gungeon-style»:
   тело всегда вертикально, направление = смена одного из 8 спрайтов (НЕ поворот),
   свободно крутится только оружие.
3. **Визуал волны будет генерироваться процедурно** (фронт «»)))», `contourAmplitude`
   = зубчатость = грязность сигнала/Distortion). Сейчас — заглушка-квадрат.
4. **Бюджет визуального шума (критично):** свои эффекты НЕ должны перекрывать
   телеграфы атак врага. Юз — в локальные читаемые сигналы (звук/хитстоп/вспышка),
   а не в экранную тряску/вспышки.
5. **Педали = преобразование именованных осей снаряда + подписка на события**, цепь
   = композиция функций, порядок применения значим. Закладывать с первой педали
   (этап 5). Перестановка педалей — только «в закулисье», не в бою.
6. **Seed-based генерация уровней** — заложить архитектурно с самого начала.

## Аудио-подход для звука гитары/волны (решено)

- Тембр (Distortion) движком в рантайме делать плохо → записываем **реальные сухие
  сэмплы**: два набора — clean и driven (palm mute, одна нота напр. открытая E,
  одинаковый уровень, 4–6 дублей). Базовый тембр выбираем **свапом сэмпла** по наличию
  Distortion в цепи, а не waveshaper-ом.
- Время/пространство (Delay/Reverb/Chorus/Compressor) — **рантайм-DSP** движка
  (`AudioEchoFilter`/`AudioReverbFilter`/`AudioChorusFilter` или группа Audio Mixer).
- Педали меняются только в закулисье → аудио-стек статичен в бою → перестраиваем его
  **раз в билд**, не на каждый выстрел.
- Аудио = «впечатление о билде», НЕ точный DSP-рендер: порядок педалей в звуке НЕ
  honorим (порядок важен только для геймплея/визуала).
- Выстрел и попадание — разные звуковые события; цепь красит выстрел, «панч»
  попадания стабилен.
- Driven-набор и DSP нужны только на этапе 5; прототипу хватает одного clean-набора.
